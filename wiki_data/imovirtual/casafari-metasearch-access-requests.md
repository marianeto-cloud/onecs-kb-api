# Overview

Casafari Metasearch is a partnership product between Imovirtual and Casafari that gives eligible real estate professionals access to the full Portuguese property market inventory in a single platform. It aggregates listings from multiple sources, deduplicates them, and provides historical price data, real-time alerts, and market analysis tools.

**Access is available to clients on the Premium bundle who have properties advertised on Imovirtual.**

This article describes the internal process for handling Casafari Metasearch access requests received by the CS team.

---

# Definitions

* **Casafari Metasearch:** A platform that centralises all property market listings (agencies + private sellers) in Portugal into a single searchable database.
* **Casafari Clients File:** A Google Sheets file that is automatically updated daily. It lists all active Imovirtual clients who have an active Casafari Metasearch subscription.

# Procedures

## 1. WHEN A CLIENT REPORTS NOT RECEIVING CASAFARI METASEARCH ACCESS

**Context:** When a client says they have not received their Casafari Metasearch access credentials, CS agents do **NOT** send the credentials themselves. It is Casafari who sends the access emails. The CS agent's role is to flag the issue directly in the shared file and request Casafari to resend.

1. Open the Casafari Clients File.
2. Search for the client in the file — use their email, agency name, NIF, or user ID to locate them.
3. **If the client IS listed in the file:**
    * Add a comment directly in the relevant row of the spreadsheet.
    * In the comment, tag both Casafari contacts.
    * Identify the client's IMO Account Manager and include their email in the comment.
4. **If the client is NOT listed in the file:**
    * The client may not have an active Casafari Metasearch subscription or may not yet be on the Premium bundle.
    * Check with the client whether they have the Premium Imovirtual bundle.
    * If eligible, direct them to **professional@imovirtual.com** to request access.

## 2. IMPORTANT NOTES

* CS agents never send Casafari access emails directly — always route through Casafari contacts via the shared file.
* The file is updated automatically every day — always use the most current version.
* Always identify and CC the client's IMO Account Manager when commenting in the file.

# FAQs

**Q: Who sends the Casafari access credentials to the client?**
A: Casafari sends the access credentials directly. CS agents do not send them.


**Q: What if I can't find the IMO Account Manager for the client?**
A: Check the client's account details in the internal tools or escalate to the team lead.


**Q: What if the client says they are on Premium but are not listed in the file?**
A: The file is updated daily. If the subscription is very recent, it may not yet appear. Ask the client to wait 24 hours and check again.
