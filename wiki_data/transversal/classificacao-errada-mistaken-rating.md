**O que é isto:** Consideramos uma classificação errada quando:

* Um comprador deixa uma classificação para certo vendedor relativamente a um produto que, claramente, não é oferecido pelo vendedor
* quando o comprador deixa uma classificação/avaliação sobre um artigo diferente daquele que comprou, vendido pelo mesmo vendedor / por outros vendedores, presumimos que o comprador confundiu os vendedores.
* Quando o comprador quer mudar a sua classificação de negativa para positiva, ou vice-versa.
* O comprador contactou vários vendedores e quer classificar o vendedor 1, mas em vez disso, classifica o vendedor 2.


**Verificar:** A avaliação para averiguar se:


* O comentário indica que o comprador está insatisfeito com um produto que não lhe foi oferecido pelo vendedor
* A interação do comprador com o vendedor (por mensagens/_chat_) a comunicar-lhe que não pretendia classificá-lo / não sabe como aconteceu.
* Não consideramos as conversas telefónicas para este efeito.

**Ação:**

Removemos classificações/avaliações se existir alguma prova de que o comprador se enganou sobre o vendedor / a oferta de produto feita pelo vendedor.


Exemplos de casos - O comprador comunicou com dois vendedores sobre dois produtos semelhantes e acabou por classificar um dos vendedores por engano.

**Código do motivo: Classificação por engano / Mistaken rating**
