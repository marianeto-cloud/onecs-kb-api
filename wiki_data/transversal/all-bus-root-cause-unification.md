# SCOPE

Customer support will have a unified root cause label structure (L1-L3) implemented in Salesforce across all business units.

So that we can improve efficiency, reduce confusion, support automation, enable better analytics, and create unified multi-skilled teams.

## What's changing?

* _Full unification_ – Root causes will be aligned across all 3 BUs - Jira ticket here.
* _Customer Success in charge_ – The team is already handling the macro updates - Jira ticket here.
* _Bilingual file_ – Available in English and Portuguese, according to your Salesforce
* _Filter by BU_ – Some RCs apply only to specific BUs. In the file, you'll see:

    → _Y_ = Available for that BU
    → _N_ = Not visible
