Ad Management — Edit, Import & Export
Overview
PRO users with the "new version ads" option have three ad management options: Edit Ads, Export Ads and Import Ads. These tools allow professional sellers to manage multiple listings, make bulk changes and publish ads using CSV files.
The features are available in the My OLX Pro section of the user account.
