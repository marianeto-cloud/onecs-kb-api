O SigningDesk e a plataforma para assinatura digital de documentos para as Entregas OLX PRO.

* Primeiro os documentos devem ser preenchidos no Lumin.
* Depois vamos criar um workflow para cada cliente no SigningDesk.

### 1. Criar workflow:
1. Clicar em Criar Workflow
2. Adicionar os documentos do cliente ja preenchidos
3. Clicar em Novo Workflow

### 2. Preencher dados do cliente:
* Nome mais data limite de assinatura
* Selecionar a opcao enviar docs assinados para o cliente
* Linha 1 Convidado: dados do cliente mais Assinante mais Assinatura simples mais Obrigar leitura mais Notificar
* Adicionar linha 2: inserir dados do OLX mais Paloma Moura mais Revisora mais Obrigar leitura mais Notificar
* Adicionar linha 3: inserir dados do OLX mais Manuel Roman mais Assinante Qualificado mais Obrigar leitura mais Notificar

### 3. Assinatura
* Abrir o documento e avancar para a pagina de Assinatura
* Arrastar o email para o campo de assinatura
* Clicar em Criar Workflow
* Clicar em Play para dar inicio ao processo

### O que o cliente recebe:
* email a solicitar assinatura de docs
* colocar codigo
* puxar para baixo a barra e ler. Clicar em assinar
